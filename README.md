# SPEC-Transfer-Documents
Assembly files to build SPEC device from University of Rochester BME Senior Design project

File names
Lid.stl - top of device

Bottom.stl - Box that holds the aluminum heat sinks

Footprint.stl - Bottom of device that is glued on to fit Tecan footprint

PrintHolderThin1.stl - Holder that sits on top of device to hold copper plate and proteochip in place on peltier chips

Fan Support.stl - Support that holds fan and is glued to bottom to device to connect
